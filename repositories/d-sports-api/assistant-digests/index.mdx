description: "Read-only backend data for the In-App Assistant."

The Assistant digest surface provides compact fan context, public game briefs, and signed-in collection search. It does not run a model or change application state.

- [API guide](/api-reference/domains/assistant-digests): endpoint inputs, access, and responses.
- [Architecture](/repositories/d-sports-api/assistant-digests/architecture): read-only boundaries, privacy, and caching.
- [Behavior](/repositories/d-sports-api/assistant-digests/behavior): rollout modes and what to expect from digest results.
