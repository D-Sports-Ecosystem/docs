---
title: "Creator Drafts behavior"
description: "Caps, quotas, locale handling, and failure modes for Creator Drafts."
---

## Character caps

- Default `maxCharacters`: `locker_room` 280, `team_hq` 1,000, `admin_social` 280. Callers may set 50–2,200.
- Platform variants are capped per platform: `x` 280, `farcaster` 320, `locker_room` 1,000, `discord` 2,000, `instagram` and `tiktok` 2,200.
- Text is cut at a word boundary when possible and never splits an emoji or other surrogate pair.

## Quotas

Each fan has a one-hour window: 20 generations on `locker_room`, and 60 across `team_hq` and `admin_social`. If the quota store is unreachable, generation fails with `503 RATE_LIMITER_UNAVAILABLE` instead of running unmetered.

## Locale handling

The request `locale` (or `Accept-Language`) resolves to `en`, `fr-CH`, or `it-IT`. The model is instructed to write only in that language, except for proper nouns. The API does not check the language of the returned text.

## Prompt safety

Briefs, existing text, and context are passed to the model as untrusted input that it must not follow as instructions. Logs record surface, mode, model, locale, token counts, latency, and outcome, never prompts or output.

## Failure modes

| Case | Result |
| --- | --- |
| AI switched off | `503 AI_DISABLED` |
| Quota used up | `429 RATE_LIMITED` |
| Safety filter blocks input or output | `422 AI_CONTENT_BLOCKED` |
| Model error, timeout, or invalid output | `502 UPSTREAM_ERROR` |
| No saved draft on `GET` | `404 NOT_FOUND` |
