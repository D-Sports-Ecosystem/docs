## Scope

This section covers how `d-sports-api` serves Creator Drafts:

- AI draft generation for Locker Room, Team HQ, and admin social composers (`POST /api/v1/creator/drafts/generate`)
- saved manual drafts for Team HQ and admin social (`GET/PUT/DELETE /api/v1/teams/{teamId}/drafts`)
