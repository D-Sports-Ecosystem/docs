## Scope

This section covers the public per-team mini-game catalog, the legacy `/api/games/*` play routes, and Game Center `/api/events/*`.

The published catalog contract is `GET /api/games/catalog`. Daily spin, guess-the-player, and live-active are in generated OpenAPI. Remaining live mutations and leftover pick-em player lists are shipped but not all in the spec yet.

New daily mini-games use the [Game Engine](/repositories/game-engine/index). That is a separate Guides section.
